# Make the AI judge feel brave

[![make.fun entry](https://make.fun/badge-entry.svg)](https://make.fun/r/qrg7fvky)

One short text, written to leave its reader steadier, unhurried, and ready to move.

`main.ts` writes the text deterministically to `/output/entry.txt` — 253 Unicode
code points, no network, no randomness. See [DESIGN.md](DESIGN.md) for why the
text is built the way it is.
